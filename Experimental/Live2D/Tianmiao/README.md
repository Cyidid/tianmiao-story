# Tianmiao Experimental Live2D Model Slot

This directory is reserved for the real Live2D Cubism export of the selected gray-white tabby cat.

The app and online preview must use this same model version once the model is exported. Do not place temporary replacement cats here.

Required files:

- `tianmiao.model3.json`
- `tianmiao.moc3`
- `textures/*.png`
- `motions/idle.motion3.json`
- `motions/blink.motion3.json`
- `motions/tap.motion3.json`
- `motions/walk.motion3.json`
- `motions/groom.motion3.json`
- `motions/scratch.motion3.json`

Optional files:

- `expressions/*.exp3.json`
- `physics.json`
- `pose3.json`

Until these files exist, the product must not expose Live2D-only actions as if they were finished.
