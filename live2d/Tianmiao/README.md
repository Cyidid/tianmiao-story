# Tianmiao Live2D Model Slot

This public preview uses the same Live2D export slot as the macOS app.

Required files after Cubism export:

- `tianmiao.model3.json`
- `tianmiao.moc3`
- `textures/*.png`
- `motions/idle.motion3.json`
- `motions/blink.motion3.json`
- `motions/tap.motion3.json`
- `motions/walk.motion3.json`
- `motions/groom.motion3.json`
- `motions/scratch.motion3.json`

Until those files and the Web SDK adapter exist, the page keeps all motion buttons disabled.
